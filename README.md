# 🅿️ Smart Parking System Simulation

A modular, Object-Oriented Python application simulating an automated smart parking garage management system. The system dynamically manages parking space allocation, tracks real-time occupancy, handles vehicle size constraints, and automates fee calculations upon exit.

---

## ✨ Features
- **Dynamic Spot Matching:** Allocates parking spots based on vehicle dimensions (`Motorcycle`, `Compact`, `Large`) to optimize space usage.
- **Automated Ticket & Fee Calculation:** Tracks vehicle entry/exit timestamps and calculates hourly billing rates automatically.
- **Real-Time Occupancy Tracking:** Provides an immediate dashboard status of available vs. occupied spots across the facility.
- **Object-Oriented Design:** Built using clean OOP design patterns (`Enums`, Encapsulation, and Single Responsibility Principle).

---

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Core Modules:** `datetime`, `enum`, `math` (standard library only — no external dependencies required)
